## 🔥 Firebase — BaaS Principal

![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)

Integração completa do ecossistema Firebase com Flutter:

- 🗃️ **Cloud Firestore** — banco NoSQL em tempo real com streams nativos no Flutter
- 🔐 **Authentication** — login social (Google, Apple), email/senha, biometria
- 📲 **FCM** — push notifications locais e remotas
- ☁️ **Cloud Functions** — lógica serverless acionada pelo app
- 🖼️ **Storage** — upload e exibição de imagens e mídia
- 📊 **Analytics + Crashlytics** — monitoramento de uso e erros em produção

## 🟢 Supabase — Open Source BaaS

![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)

Alternativa robusta ao Firebase, com PostgreSQL como base:

- 🐘 **PostgreSQL gerenciado** com queries avançadas e joins reais
- 🔐 **Row-Level Security (RLS)** — controle de acesso granular por usuário
- ⚡ **Realtime** — subscriptions reativas integradas ao Flutter
- 🔑 **Auth** — JWT, OAuth, magic links, sessões
- 🗂️ **Storage** — buckets com políticas de permissão
- 🌐 **Edge Functions** — lógica serverless com Deno

## 🏗️ Arquitetura & Boas Práticas

> Código que escala — porque app profissional exige estrutura profissional.

```
📁 lib/
 ├── core/           # Erros, constantes, injeção de dependência
 ├── data/           # Repositories (impl), datasources, models
 ├── domain/         # Entities, use cases, interfaces de repositórios
 └── presentation/   # Pages, widgets, BLoC/Cubit, ViewModels
```

- ✅ **SOLID** — princípios aplicados em cada camada
- ✅ **Clean Architecture** — separação clara de responsabilidades
- ✅ **BLoC Pattern** — gerência de estado reativa e testável
- ✅ **TDD** — testes unitários e de widget com Mockito
- ✅ **CI/CD** — GitHub Actions para lint, test e build automático
